### Room 1 — The Anteroom (Entry Hall)
*First impressions. Fairly simple to ease players in.*

**Objects:**
- **Hat rack** (prop, clicking on the rack gives description 'It's a hat rack, what did you expect'")
- **Hat #1** (prop, overlapping on top of hat rack. clicking on it gives 'It's a REALLY cool hat.' Searching the hat gives 'It's a REALLY cool hat.' Can be picked up)
- **Hat #2 (Wizard hat)** (prop, overlapping on top of hat rack. clicking on it gives 'Don't ask me why this is here'. Searching it gives 'Found the answer to life' Can be picked up)
- **Hat #3** (prop, overlapping on top of hat rack. clicking on it gives 'Hat. It's a hat.'. Searching it gives 'You find a hidden compartment with a UV flashlight')
- **Filing inbox** (cover) → description of 'Lot's of juicy things in here!'searching finds "Employee Badge" (used in later puzzle) and torn half of a cipher key: Substitution Cipher between letters and random ASCII characters. Give first half of alphabet
- **Wall clock** (device, stopped at 8:37) seaching gives 'Lots of dust'
- **Carpet** (prop) searching gives 'everyone searches the carpet'. Using UV flashlight gives text 'hour times min'.
- **Locked cabinet** (safe, 3-digit code) → contains "Secret Key" → opens door to Room 2
  - Code: 296
- **Electical Socket** search gives "Shocking". When used with wire from room 2 activates power grid in room 3. Electrical socket is not moved

### Room 2 — The Library / Archive
*Mid-difficulty.*

**Objects:**
- **Bookshelf #1** (cover) → Search gives a paragraph excerpt from a book
- **Bookshelf #2** (cover) → Search gives: 'Many books' UV gives Gives a string of 4 numbers
- **Notebook** search: torn half of cipher key, gives second half of alphabet; 
- **Typewriter** (puzzle) → For each number in the hidden text in bookshelf 2, find the word that is that number away from the start and type it. when the 4 words are put together a hidden compartment is unlocked with a "wire"
- **Blackboard** (note) → Contains a simple math equation. Using chalk from room 3 allows you to write the answer to that math equation, giving you text that is encrypted using the cipher in the cipher keys
- **Safe** Searching gives 'Its a safe. Employees only' using employee badge opens it, giving you 'Confidential Papers'. The paper contains a text such that the first letter of each sentence spells out "REDBLUERED'.
- **Computer** (Description: "I forgot my password"), requires mainframe terminal to be solved, once unlocked allows user to analyze "boring data" from room 3 (description 'Analyzes Data') once data analyzed gives back 3892
- **Door to Room 3** → requires Red Access Card

### Room 3 — The Laboratory
*Complex, multiple parallel threads.*

**Objects:**
- **Item Analyzer** description is "Searching for REALLY cool items" when given the really cool hat from room 1 gives back "boring data". 
- **Labled Potion** seaching gives "Turns out the label was empty" using UV pen gives "First Letters"
- **Chemical mixer** (puzzle) → color combinations, 5 colors. Answer is RED BLUE RED. Mixing gives 'Acid'
- **Power grid panel**  "Power offline". When solved via the electical socket, the power turns on it turns on mainframe terminal
- **Mainframe terminal** (puzzle, text input) → Doesn't work until power is online. Once power is online it activates and you have to type in the password which is found using the cipher key and text hidden in the black board. Once unlocked, unlocks computer in room 2
- **Locked Cabinet** using acid opens cabinet revealing chalk
- **Exit** (door) → Requires passcode "3892" to exit
